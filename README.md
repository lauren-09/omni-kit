# OmniKit

An all-in-one toolbox for everyday file tasks: convert and compress images, convert documents and ebooks, edit PDFs, convert video and audio, make GIFs, and zip files.

**Goal:** a simple, free tool for personal use, with no sign-ups, ads, tracking or hidden costs.

**Private by design:** everything runs in your browser. Files are never uploaded to a server.

## Run locally

```bash
npm install
npm run dev
```
